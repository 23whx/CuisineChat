# Sketch 001: UI Direction

## Design Question
CuisineChat（P2P 臨時聊天室）首頁與聊天室應該採用哪一種整體視覺方向？

## How to View
open .planning/sketches/001-ui-direction/index.html

頂部切換方案；右下角工具列切換「手機並排 / 桌面首頁 / 桌面聊天室」。

## Variants
應用戶要求一次給出 6 個方向（超出 skill 預設的 2–3 個），以便第一輪直接挑方向。
- **A: 清爽綠** — 沿用現有微信綠，只整理層級與細節；改動成本最低
- **B: 美食雜誌** — 奶油紙、Fraunces 襯線大標、陶土紅；寬螢幕成員側欄
- **C: 深夜食堂** — 暗色、燈籠琥珀、暖簾；私密夜晚氛圍
- **D: 便當盒** — 粗黑描邊、偏移陰影、粉彩色塊、圓體字；活潑
- **E: 點菜單** — 票據紙、等寬字、印章紅；聊天呈現為日誌
- **F: 霧玻璃** — 漸層光暈、毛玻璃懸浮標題列與輸入框、iMessage 藍

## Decision
用戶選定 **C 深夜食堂**：暗色底（#15110e）、燈籠琥珀色（#f2a541）作主色與自己的訊息氣泡、暖簾紅（#d64933）作點綴、Noto Serif TC 作標題字，主按鈕與自己的氣泡帶琥珀色微光。

## What to Look For
- 長時間閱讀聊天時是否舒服（對比、氣泡辨識度）
- 圖片 / 語音 / 文件訊息在各方案中的辨識度
- 首頁是否一眼看懂「房間號 + 3 位密碼」
- 中日韓字體混排效果、手機與桌面兩種寬度
